# Collections – 2022

## 1. How collections work

### 1.1 Symbols and action key (p. 238–239)

- → Task.  
- O Event.  
- - Note.  
- X → Done / completed.  
- * Important.  
- >> Short‑term work worth time for migration.  
- << Long‑term tasks that are not worth time.  
- ~ Cross out tasks that are not worth time. [file:1]

- Inspiration:
  - ! → Inspiration, paired with a note (great ideas, mantras, insights). [file:1]
- Delegation:
  - @Name → delegated task; once done, convert to X, leaving the @Name for attribution. [file:1]

- Collections start from the back of the notebook and move forward so they meet the daily logs in the middle. [file:1]
- Use Action Method style:
  - Roughly 1 page of collection per 1.5 days of work on a project (45‑day project ≈ 3 pages). [file:1]
- Threading:
  - `#‑MM‑DD Thread Forward` – forward link into the dailies.  
  - `<p‑MM‑DD Thread Backward` – back‑link into a prior daily. [file:1]

**Action key reference:**

- Structure: `Action][Person][Subject][Short‑code]`. [file:1]
- Shortcodes:
  - Q – Question.  
  - Obs – Observation.  
  - Sta – Statement.  
  - Opin – Opinion.  
  - Tht – Thought. [file:1]
- Actions:
  - Email, Call, Schedule, F.U. (follow‑up). [file:1]
