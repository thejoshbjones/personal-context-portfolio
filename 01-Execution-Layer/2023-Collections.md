# Collections Instructions & Keys (p.238)

- L Key / Action Key Reference: `•` = Note, `O` = Event, `→` = Task, `X` = Done / Completed, `*` = Important. [file:1]
- Short‑term tasks worth migrating: `>>` mark. [file:1]
- Long‑term tasks not worth migrating: `<+` mark; cross out tasks that are not worth time long‑term. [file:1]
- Collections start at the back and work toward the front so you meet in the middle. [file:1]
- Use collections with the Action method for meetings. [file:1]
- 1 page for a collection project for every ~18 days (45‑day project ≈ 3 pages). [file:1]
- Threading:
  - `py #-MM-DD` = thread forward.
  - `py #-MM-DD` = thread backward. [file:1]
- Inspiration pages are paired with a note: personal mantras, genius insights, great ideas. [file:1]
- Delegated tasks: add who & what with `@Name – task` (e.g., `@Kevin – this action`), and turn `/` into `X` when complete. [file:1]
- Structure pattern: `[Action][Person][Subject][Shortcode] ref:[page]`. [file:1]
- Shortcode list: `Q` = Question, `Obs` = Observation, `Sta` = Statement, `Opn` = Opinion, `Tht` = Theory. [file:1]
- Common actions: Email, Call, Schedule, F.U. (Follow Up). [file:1]
