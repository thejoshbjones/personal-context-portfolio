# Key

## Task and event markers

- `X` – completed task.
- `>` – task/thread migrated forward (see end of line for next page and date).
- `<` – task/thread reference backward to a previous page and date.
- `O` – event.
- `-` – note line or note group.

### Semantic markers

- `tht` – thought.
- `obs` – observation.
- `Q` – question.

## Suggested Markdown normalization

- `X` → `- [x]` (completed task).
- Open task (no mark) → `- [ ]`.
- `>` → `- [>]` with “threaded to p.# YYYY‑MM‑DD”.
- `<` → `- [<]` with “threaded from p.# YYYY‑MM‑DD”.
- `O` → `- [o]` event.
- `tht` → `- tht: …`.
- `obs` → `- obs: …`.
- `Q` → `- Q: …`.
- `-` → simple note bullet. [file:1]
