## Action Key / Bullet Journal Legend (p.398)

- Symbols:  
  - `□` task, `○` event, `–` note.  
  - `X` completed, `*` important, `>` short‑term migration, `<` long‑term not worth time now.  
  - `~` crossed‑out / no longer worth doing.  
- Collections guidance:  
  - Start collections at the back and work toward the front.  
  - Use with Action Method for meetings.  
  - 1 page per collection/project per ~15 days (e.g., 45‑day project in 3 pages).  
  - `--> pg#-MM-DD` = thread forward, `<-- pg#-MM-DD` = thread backward.  
- Action structure pattern:  
  - `[Action][Person][Subject][Shortcode] ref:[page]`.  
  - Example shortcodes: QF (question email), Obs (observation), Sta (statement), Opin (opinion), Tht (thought), FV (follow up).  
- Delegation notation:  
  - `@Name – this action`, mark complete by adding a trailing `/` to make `X`.

## Bullet Journal Legend & Action System (p.398)

### Symbols

- `□` – Task.  
- `○` – Event.  
- `–` – Note.  
- `X` – Completed item.  
- `*` – Important / high‑priority.  
- `>` – Short‑term migration (move soon).  
- `<` – Long‑term / not worth time now.  
- `~` – Crossed out / no longer worth doing.  

### Collections Guidance

- Start collections at the back of the notebook and work forward; daily logs go from the front backward.  
- Use in conjunction with the Action Method for meetings and projects.  
- Rough sizing: one page per collection/project per ~15 days (e.g., 45‑day project ≈ 3 pages).  
- Threading notation:  
  - `--> pg#-MM-DD` = thread forward to the next page/date.  
  - `<-- pg#-MM-DD` = thread backward to the prior page/date.  

### Action Structure Pattern

- General pattern:  
  - `[Action][Person][Subject][Shortcode] ref:[page]`.  
- Example shortcodes:  
  - `QF` – Question (e.g., email).  
  - `Obs` – Observation.  
  - `Sta` – Statement.  
  - `Opin` – Opinion.  
  - `Tht` – Thought.  
  - `FV` – Follow‑up.  

### Delegation Notation

- `@Name – this action` to assign a task.  
- Mark completion with a trailing slash or an `X` on the item.
