# Key

- [ ] Task -> Task
 - Task -> Event
- -Task -> Note
 - [x] Done/Completed
- *Task -> Important
[ ] > Task ->  Short term worth time for migration
- [ ] < Task -> Long term tasks that aren't worth time now
 - [ ] ~~Task~~ -> cross out tasks that aren't worth time long term

Collections -> start out at back and work to front so that you meet in the middle.
- Use collections w/ Action Method for meetings.
- 1 page for collection project for every 15 days. (45 day project in 3 pages)

-->pg#-MM-DD Thread Forward
<--pg#-MM-DD Thread Backward

"!" → Inspiration. Paired w/ a note. Think. Great Ideas. Personal Mantras. Genius Insights.
- [ ] / -> Delegated Tasks. Add the who & what with a @Name and task. (i.e. @kevin – this action & once done turn slash into X by adding \.)
"+" ->  for longer formed note.
