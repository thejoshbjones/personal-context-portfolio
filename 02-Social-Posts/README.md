# LinkedIn Posts

A chronological archive of published LinkedIn posts.
Each file contains posts grouped by month or topic.

## File Naming
M-D-YY.md (e.g. 6-23-26.md)
If two posts on the same day: M-D-YY-2.md

## File Format
Each file contains:
1. [[LinkedIn Map]] — Obsidian backlink
2. LinkedIn post URL
3. Full post text as published
