## Script Internals - How It Works

```
┌─────────────────────────────────────────────────────────────────┐
│ thread_tasks.py --mode monthly --current-page 47                │
└─────────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────────┐
│ Step 1: Detect Portfolio Path                                  │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ Try: /sessions/.../personal-context-portfolio ✓             │ │
│ │ If fail, try: /Users/joshuajones/GitHub/...                │ │
│ │ If fail, try: ~/GitHub/personal-context-portfolio           │ │
│ │ If fail, ask for --portfolio-path                           │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────────┐
│ Step 2: Find Month File                                        │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ Try: 2026-July.md ✓                                         │ │
│ │ If fail, try: 2026-07.md                                    │ │
│ │ If fail, error with helpful message                         │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────────┐
│ Step 3: Scan for Open Tasks                                    │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ Read entire file                                            │ │
│ │ Find date sections: ## YYYY-MM-DD (p.XX)                   │ │
│ │ Find open tasks: - [ ] Task text                           │ │
│ │ Filter: Only dates before today                            │ │
│ │ Skip: Tasks with --> already                               │ │
│ │ Return: [(date, page, task_text), ...]                     │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────────┐
│ Step 4: Show Preview                                           │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ Print: Found X tasks                                        │ │
│ │ Print: From/To dates and pages                             │ │
│ │ List: Each task with [date p.page] prefix                  │ │
│ │ Ask: "Apply these changes? (yes/no):"                      │ │
│ │ Wait: For user input                                        │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                           ↓
                      ┌────┴────┐
                      │  User   │
                      │  Input  │
                      └────┬────┘
                ┌──────────┴──────────┐
                ↓                     ↓
        ┌───────────────┐     ┌──────────────┐
        │ User says "no"│     │ User says    │
        │               │     │ "yes"        │
        └───────┬───────┘     └──────┬───────┘
                ↓                     ↓
        ┌───────────────┐     ┌──────────────────────────────────┐
        │ Status:       │     │ Step 5: Apply Changes            │
        │ CANCELLED     │     │ ┌──────────────────────────────┐ │
        │               │     │ │ For each open task:          │ │
        └───────────────┘     │ │ 1. Add -->pgPAGE-M-D to src │ │
                              │ │ 2. Strip [KRISP: ...] if any│ │
                              │ │ 3. Create task on target    │ │
                              │ │ 4. Add <--pgPAGE-M-D to it  │ │
                              │ └──────────────────────────────┘ │
                              └──────────────┬───────────────────┘
                                            ↓
                              ┌──────────────────────────────────┐
                              │ Step 6: Write File               │
                              │ ┌──────────────────────────────┐ │
                              │ │ Write modified content back  │ │
                              │ │ (atomic operation)           │ │
                              │ └──────────────────────────────┘ │
                              └──────────────┬───────────────────┘
                                            ↓
                              ┌──────────────────────────────────┐
                              │ Step 7: Report Success           │
                              │ ┌──────────────────────────────┐ │
                              │ │ Status: SUCCESS              │ │
                              │ │ Message: Threading complete  │ │
                              │ │ Tasks threaded: X            │ │
                              │ └──────────────────────────────┘ │
                              └──────────────────────────────────┘
```

## Data Flow Diagram

```
┌─────────────────────────────────────────────────────────────────────┐
│ Input: --current-page 47 --mode monthly                            │
└─────────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────────┐
│ Portfolio: /sessions/.../personal-context-portfolio/                │
│            01-Execution-Layer/2026-July.md                          │
└─────────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────────┐
│ Raw File Content (3000+ lines)                                      │
│ ┌─────────────────────────────────────────────────────────────────┐ │
│ │ ## 2026-07-01 (p.46)                                            │ │
│ │ - [x] Completed task                                            │ │
│ │ - [ ] Open task from July 1                                    │ │
│ │                                                                 │ │
│ │ ## 2026-07-07 (p.47)                                            │ │
│ │ - [ ] Task A <--pg46-7-6                                       │ │
│ │ - [ ] Task B <--pg46-7-6                                       │ │
│ │ - [ ] Task C [KRISP: Meeting 7-6]                              │ │
│ │                                                                 │ │
│ │ ## 2026-07-13 (p.47)                                            │ │
│ │ - [ ] Existing task 1                                           │ │
│ │ - [ ] Existing task 2                                           │ │
│ └─────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────────┐
│ Regex Extraction                                                    │
│ ┌─────────────────────────────────────────────────────────────────┐ │
│ │ Pattern: ## (\d{4}-\d{2}-\d{2}) \(p\.(\d+)\)                   │ │
│ │ Pattern: - \[ \] (.+)$                                          │ │
│ │                                                                 │ │
│ │ Found:                                                          │ │
│ │ ("2026-07-07", "47", "Task A <--pg46-7-6")                     │ │
│ │ ("2026-07-07", "47", "Task B <--pg46-7-6")                     │ │
│ │ ("2026-07-07", "47", "Task C [KRISP: Meeting 7-6]")            │ │
│ └─────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────────┐
│ Filtering & Processing                                              │
│ ┌─────────────────────────────────────────────────────────────────┐ │
│ │ Filter: date < today (2026-07-14) ✓                            │ │
│ │ Filter: not already threaded forward (no -->) ✓                │ │
│ │ Strip KRISP: "Task C [KRISP: ...]" → "Task C"                  │ │
│ │                                                                 │ │
│ │ Output:                                                         │ │
│ │ [("2026-07-07", "47", "Task A"), ...]                          │ │
│ └─────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────────┐
│ Preview Display (User confirms)                                     │
└─────────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────────┐
│ Modified File Content                                               │
│ ┌─────────────────────────────────────────────────────────────────┐ │
│ │ ## 2026-07-07 (p.47)                                            │ │
│ │ - [ ] Task A <--pg46-7-6 -->pg47-7-13           [ADDED]        │ │
│ │ - [ ] Task B <--pg46-7-6 -->pg47-7-13           [ADDED]        │ │
│ │ - [ ] Task C [KRISP: Meeting 7-6] -->pg47-7-13  [ADDED]        │ │
│ │                                                                 │ │
│ │ ## 2026-07-13 (p.47)                                            │ │
│ │ - [ ] Existing task 1                                           │ │
│ │ - [ ] Existing task 2                                           │ │
│ │ - [ ] Task A <--pg47-7-7                        [NEW]          │ │
│ │ - [ ] Task B <--pg47-7-7                        [NEW]          │ │
│ │ - [ ] Task C <--pg47-7-7                        [NEW, STRIPPED]│ │
│ └─────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────────┐
│ Output: SUCCESS, 3 tasks threaded                                   │
└─────────────────────────────────────────────────────────────────────┘
```
